# 产品路线图与商业化设计（v1 头脑风暴）

*角色视角：高级产品经理。目标：把「永铭 Evermark」从可用的 MVP 变成有复利的长青产品。*

> **交付状态（2026-07）**：本文档规划的 v2 全部功能已上线（时间轴、声音遗产、AI 生平、众筹记忆、纪念卡、.ics 提醒、烛光累积、节日模式、记忆之墙）。v3 亦已交付：账户体系（邮箱/钱包登录）、按量计费 + 固定档位充值（Stripe）、生者/逝者双形态、守望机制（不活跃计时 → 亲友确认 → 冷静期 → 链上 transition）、时光记录（签名 entry 独立上链）、记忆星海首页（黄金角螺旋 + 缩放漫游）、数据自证页 `/permanence`、设计系统 v2（纸纹/动效/双情绪）。v4 已交付：密钥账户托管与无密钥化主流程（跨设备即登即管）、我的星、时光提醒、守望伦理约定页。时间胶囊与大文件直传仍为后续方向。

## 0.5 登录服务选型（Supabase / Clerk 评估结论）

结论：**当前阶段保留自研轻量认证，生产扩张期再引入托管身份服务补充 OAuth。**

- 现状已覆盖核心需求：邮箱验证码 + 钱包 personal_sign 登录、JWT 会话、与账本/守望/密钥托管共用一套 `users` 表，全链路已 E2E 验证；无按 MAU 计费、无外部依赖。
- **Clerk**：接入最快（Next.js 中间件 + 组件即用），带 Google/Apple 一键登录、MFA、设备管理；但按 MAU 收费、供应商锁定，且大陆访问与本土登录方式（微信/手机号）支持弱。适合以海外用户为主的扩张期。
- **Supabase Auth**：开源、可自托管、免费额度充足；但深度绑定其 Postgres 体系（本项目为 Turso/libSQL），Web3 钱包登录需自行扩展——迁移收益与改造成本不成正比。
- 引入时机与路径：当需要社交一键登录（注册转化）或 MFA 时接入。`users` 表保持为身份主表、新增 `authProviderId` 列，托管服务只作为「登录方式提供者」，回调后换发本站会话——认证入口可替换，账本/守望/托管等身份关联零改动。中国市场路径则是自建微信/手机号 OTP，托管服务均无法替代。

## 0. 一个核心洞察

纪念产品与几乎所有互联网产品相反：**它的价值随时间增长，而非衰减**。一张 2026 年上传的照片，在 2066 年比今天珍贵一百倍。因此：

- 护城河不是功能，而是**沉淀下来的、不可迁移的记忆内容**；
- 留存的杠杆不在创建者（一生一次），而在**缅怀者**（可以年复一年回来）；
- 一切设计决策都应回答：*这能否让更多记忆沉淀进来，或让人们更常回来缅怀？*

北极星指标建议：**月度缅怀行为数**（献花+点烛+留言+回访）。当它持续大于新建数，产品就进入了复利区间。

## 1. 功能头脑风暴

### A. 情感深度（让一座碑变成一段人生）

| 功能 | 说明 | 价值 |
|---|---|---|
| **生平时间轴** | 按年代的事件卷轴：出生、求学、成家、成就……滚动即叙事 | 把"一段简介"升维成"一部传记"；付费点 |
| **声音遗产** | 上传一段逝者的语音/一首 TA 常哼的歌，"点击，听 TA 的声音" | 音频文件小、上链便宜，情感冲击力是照片的十倍 |
| **AI 辅助写生平** | 访谈式引导（"TA 常说的一句话是？""TA 最骄傲的事？"）生成初稿再润色 | 大多数人不是不想写，是不会写——这是**创建转化率**的最大杠杆 |
| **众筹记忆（故事接龙）** | 亲友凭链接提交各自的记忆片段，创建者审核后并入 | 墓碑从一人所写，变成一群人共同拼出的一生；每个投稿者都成为传播节点 |
| **时间胶囊 / 未来信** | 写给几十年后孙辈的信，客户端加密+定期公开 | 打开"生前自建"市场：从"纪念逝者"扩展到"给未来留言" |

### B. 回访与传播（把低频做成有节律）

| 功能 | 说明 | 价值 |
|---|---|---|
| **纪念日提醒** | 忌日、诞辰、清明/中元/冬至，邮件或 .ics 日历订阅（无需注册账号） | 一年多次把访客带回来——低频产品的节律化 |
| **集体缅怀时刻** | 清明夜首页进入"烛光模式"，全站深色+烛海；"今晚已有 N 人点烛" | 制造集体仪式感与社交传播时刻 |
| **烛与花的可视累积** | 献过的烛真实地亮在页面上，花瓣有飘落动画 | 让每次微小行为留下可见痕迹（已有计数，升级为可视化） |
| **精美分享卡** | 一键生成竖版纪念卡图（姓名+肖像+墓志铭+二维码） | 微信/朋友圈传播的原生载体 |
| **「历史上的今天」发现流** | 今日诞辰/忌辰的公开纪念页 | 给缅怀长廊一个每天都不同的入口 |

### C. 信任与永久性自证（差异化的根）

| 功能 | 说明 | 价值 |
|---|---|---|
| **数据自证页** | "如果本站消失怎么办"：多网关入口列表、一键导出静态版、开放 schema 文档 | 反直觉但正确：**越开放越可信，越可信越付费** |
| **继承人机制** | 管理密钥 Shamir 2/3 分片交给亲友；或指定继承人 | 回答"我死后谁来维护我的页"——生前市场的前提 |
| **家族树关联** | 纪念页之间建立关系（父母/子女/伴侣），逐渐织成家族记忆网络 | 网络效应的种子：一个家族一旦落户，很难离开 |

## 2. UI/UX 设计原则

1. **双模式设计**：创建 = 仪式（庄重的步骤、像点烛一样的进度感）；访问 = 沉浸叙事（滚动即故事，零操作负担）。两种心境，两套节奏。
2. **仪式微交互**：点烛时屏幕微微变暗、火苗亮起再回明——把一次点击变成一次小小的仪式。克制的动效（150-300ms、慢半拍），永不使用弹跳/炫技动画。
3. **移动优先的缅怀**：扫墓、守灵、深夜想念都发生在手机上；献花点烛必须单手可完成。
4. **长辈友好**：大字模式开关、高对比、全程无术语（现有的"免钱包"路线继续贯彻到每一个文案）。
5. **氛围系统**：已有的纸墨鎏金 + 烛光 halo 是对的；下一步让氛围随时刻变化（夜晚访问自动更暗更暖、纪念日当天页面有细微的白菊元素）。

## 3. 商业化设计

### 收入分层（按落地顺序）

1. **免费层（信任基石，永不收回）**：文字 + 3 张照片，永久存储。免费本身就是获客与信任的广告——"我们敢免费永久，因为成本一次性锁定"。
2. **永久典藏（一次性 ¥199-399 / $49-99）**：12+ 照片、视频、语音、生平时间轴、AI 写作助手、定制主题。锚点：ForeverMissed 终身版 $155；我们以"架构级真永久"支撑同档定价。存储成本 <$1/页，**毛利 >95%**。
3. **实体二维码牌（¥199-499）**：金属蚀刻牌，贴于墓碑/骨灰堂/牌位，扫码即达数字空间。殡葬场景刚需、客单高、天然礼品属性——线上线下的桥。
4. **B2B 白牌与 API**：殡仪服务商、陵园、**寿险公司**（作为保单增值服务赠送数字纪念页）。死亡产业有现成销售网络，这是规模化的主渠道。
5. **生前存档（订阅或高价一次性）**：私密维护的"人生存档 + 数字遗嘱"，由继承人在身后启封公开。把 TAM 从"事后纪念"扩展到"生前规划"。

### 明确不做

- **广告**：一条广告就能毁掉全部氛围与信任；
- **代币/NFT 炒作**：与"庄重"人设冲突，且监管风险；
- **按年收存储费**：违背"永久"的核心承诺（这是竞品的软肋，不能变成我们的）。

### 优先级（RICE 粗排）

- **P0（先提转化与信任）**：AI 辅助写生平、生平时间轴、声音遗产、数据自证页、分享卡
- **P1（再做回访与首个硬变现）**：纪念日提醒、集体缅怀时刻、众筹记忆、实体二维码牌
- **P2（长期壁垒）**：家族树、继承人机制、B2B 白牌、生前存档

### 风险提示

- **先信任后收费**：内容量与口碑未起时过早收费会杀死飞轮，前 1000 座碑应不惜成本免费；
- **中文市场落地**：支付（微信/支付宝）与合规（ICP/区块链备案）需独立评估，建议先全球站验证产品；
- **AI 成本**：写作助手按次调用需设免费额度上限，纳入典藏付费层。
